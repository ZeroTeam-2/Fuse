# local-dev-environment — delta

## ADDED Requirements

### Requirement: Раздельные dev-процессы API и воркера

Локальная разработка SHALL запускать API и воркер исполнения сценариев отдельными процессами на хосте. Команда `pnpm dev` MUST поднимать фронтенд, API и воркер вместе; воркер MUST также запускаться самостоятельно (`pnpm dev:worker`) — например, вторым терминалом рядом с уже работающим API. Оба процесса MUST работать в watch-режиме, и их watch-циклы MUST быть независимыми: пересборка/рестарт одного процесса MUST NOT прерывать или пересобирать другой.

#### Scenario: pnpm dev поднимает полный стек

- **WHEN** разработчик выполняет `pnpm dev` при поднятой инфраструктуре и активном локальном профиле
- **THEN** стартуют фронтенд, API-процесс и воркер-процесс, и запуск сценария из локального UI доходит до терминального статуса

#### Scenario: Рестарт API не прерывает исполнение

- **WHEN** во время исполнения запуска воркером разработчик меняет код API (или API-watch перезапускается по любой причине)
- **THEN** воркер-процесс продолжает исполнение без прерывания, запуск не осиротевает до visibility timeout, а клиент после реконнекта WebSocket получает актуальный снапшот

#### Scenario: Воркер запускается отдельно

- **WHEN** разработчик выполняет `pnpm dev:worker` без запущенного API
- **THEN** воркер-процесс стартует, подключается к локальной очереди и обрабатывает сообщения; отсутствие API влияет только на доставку WS-событий клиентам, но не на исполнение шагов
